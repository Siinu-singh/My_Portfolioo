# **App Name**: Suraj Portfolio

## Core Features:

- Resume Display: Display the resume content in a structured format.
- 3D Effects: Implement 3D effects for visual appeal.
- Localhost Setup: Configuration to run the Next.js project on a localhost machine.

## Style Guidelines:

- Primary color: Dark blue (#1A202C) for a professional look.
- Secondary color: Light gray (#EDF2F7) for content areas.
- Accent: Teal (#4DC0B5) for interactive elements and highlights.
- Modern, single-page layout with smooth scrolling.
- Use a consistent set of professional icons for skills and contact information.
- Subtle animations on scroll and hover for an engaging experience.
